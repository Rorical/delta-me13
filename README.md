# 翁法罗斯 - Omphalos Simulation

一个基于AI的多代理模拟系统，重现了史诗般的"逐火之旅"世界。在这个被黑潮威胁的世界中，黄金裔们必须挑战十二泰坦，收集火种，完成再创世的使命。

## 🌟 项目特色

### 🎭 丰富的角色系统
- **黄金裔 (Golden Heirs)**: 被选中的逐火者，拥有独特的路径和原动力
- **泰坦 (Titans)**: 远古守护者，守护着火种，测试挑战者
- **NPC**: 商人、工匠、守卫、学者，支持黄金裔的逐火之旅

### 🌍 复杂的世界观
- **城邦系统**: 多种类型的城市，各有特色和资源
- **黑潮威胁**: 不断蔓延的腐蚀力量，推动剧情发展
- **火种系统**: 十二枚火种，再创世的关键
- **时间纪元**: 动态的时间系统，影响世界发展

### 🤖 AI驱动的智能代理
- **真实对话**: 支持 OpenAI Responses、OpenAI 兼容端点、Anthropic 与 DeepSeek 的大模型驱动
- **智能决策**: 每个代理都有独特的性格和目标
- **记忆系统**: 长期和短期记忆，影响决策
- **情感系统**: 代理间的关系和互动

## 🚀 快速开始

### 环境要求
- Node.js 18+
- 任一模型服务的 API Key（OpenAI / Anthropic / DeepSeek / OpenAI 兼容端点）

### 安装步骤

1. **克隆项目**
```bash
git clone https://github.com/your-username/delta-me13.git
cd delta-me13
```

2. **安装依赖**
```bash
npm install
```

3. **启动开发服务器**
```bash
npm run dev
```

4. **访问应用**
   - 打开浏览器访问 `http://localhost:5173`
   - 在「再创世 / 因果矩阵」中选择调用协议、填写密钥与模型并测试连接
   - 点击"启动仿真"开始体验

## 🎮 系统功能

### 核心模拟系统
- **实时仿真**: 多代理并行决策和行动
- **智能调度**: 随机代理执行顺序，支持对话链
- **状态同步**: 前端实时更新世界状态
- **事件日志**: 详细记录所有活动和事件

### 代理能力
- **移动 (MOVE)**: 沿城邦间的道路移动，每天前进一站，远方目的地自动寻路
- **对话 (CHAT)**: 与同城者交流，对方当日即可回应
- **挑战 / 战斗 (ATTACK)**: 同城盟友协同作战，泰坦会反击；击败泰坦即可夺取火种
- **结盟 (FORM_ALLIANCE)**、**观察 (INSPECT)**、**防御 (DEFEND)**、**休息 (REST)**
- **采集 (GATHER)** / **制作 (CRAFT)** / **使用物品 (USE_ITEM)**: 食物、材料、魔力 → 武器、护甲、药剂
- **交易 (TRADE)** / **赠送 (GIFT)**: 同城物品交换，关系影响对方是否接受
- **建造 (BUILD_DEFENSE)** / **净化 (CLEANSE)**: 修筑城防、驱散所在城邦的黑潮
- **授予火种 (BESTOW_EMBER)**: 尚存神智、被说服的泰坦，可把火种交给认可度 ≥ 30 的黄金裔
- **归还火种 (RETURN_EMBER)**: 在创世涡心归还火种，承载神权成为「半神」；十二火种全部归还即完成再创世

### 用户界面
- **实时监控**: 代理状态和世界指标
- **事件日志**: 可过滤的重要事件记录
- **全屏模式**: 沉浸式日志查看
- **系统控制**: 启动、停止、重置仿真

## 🏗️ 技术架构

### 前端技术栈
- **Vue 3**: 现代化的前端框架
- **TypeScript**: 类型安全的开发体验
- **Vite**: 快速的构建工具
- **CSS Grid/Flexbox**: 响应式布局

### 后端模拟系统
- **多代理系统**: 基于AI的智能代理
- **状态管理**: 复杂的世界状态管理
- **事件系统**: 动态事件生成和处理
- **记忆系统**: 代理的长期和短期记忆

### AI集成
- **多协议模型接入**（`src/core/providers.ts`）:
  - OpenAI Responses API：推理模型使用 reasoning effort，并记录推理摘要
  - OpenAI Chat Completions：兼容 vLLM、OpenRouter、Ollama 等端点
  - Anthropic Messages API：浏览器直连；新一代 Claude 使用自适应思考与 effort，旧款使用思考预算；官方端点上的 `claude-opus-5` / `claude-fable-5-1` 默认启用服务器端拒绝回退
  - DeepSeek V4（`deepseek-v4-pro` / `deepseek-v4-flash`）：`thinking` 思考模式与 `reasoning_effort`
  - 模型返回的思考内容会显示在仿真的「因果矩阵」调用日志中
- **智能对话**: 上下文感知的对话系统
- **个性化**: 每个代理的独特性格和行为

│   │   ├── memory.ts           # 近况 + 摘要式记忆

## 🎯 核心概念

### 一天的流程
1. **决策**：黄金裔每天行动，居民按活跃度抽样，泰坦只在有人来访时醒来；所有决策按并发上限并行请求
2. **结算**：按随机顺序执行动作，结果（包括失败原因）写入各自记忆，下一次决策可见
3. **回应**：当天被搭话的人再做一次简短回应
4. **演化**：黑潮扩散与城防减免、资源再生、随机异象、倒下者苏醒

### 世界设定
角色、泰坦与城邦的称号和描述参照游戏内文本整理：十二泰坦分为命运（雅努斯、塔兰顿、欧洛尼斯）、支柱（吉奥里亚、法吉娜、艾格勒）、创生（刻法勒、瑟希斯、墨涅塔）、灾厄（尼卡多利、塞纳托斯、扎格列斯）四组；逐火十二英雄为白厄、昔涟、阿格莱雅、缇宝、万敌、那刻夏、遐蝶、风堇、赛飞儿、刻律德菈、海瑟音、丹恒•腾荒。

### 纪元轮回
- 十二火种尽数归还创世涡心 → 再创世，进入下一纪元
- 世界黑潮 ≥ 85% 或 8 座城邦沦陷 → 世界被吞没，永劫回归再度开启
- 每个纪元的黑潮都更凶猛；代理只保留上一轮的模糊残响

## 🔧 开发指南

### 自定义动作类型
1. 在 `core/agent/actions.ts` 中添加动作类型、说明与允许的代理种类
2. 在 `core/engine.ts` 的 `dispatch()` 中实现结算逻辑

### 调整世界
- 城邦与道路：`core/config/cities.ts`
- 角色设定：`core/agent/goldenHeirProfiles.ts`、`titanProfiles.ts`、`npcProfiles.ts`
- 平衡参数：`core/engine.ts`（战斗、黑潮增长、净化量）
